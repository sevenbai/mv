# 播放結束 Replay 按鈕 — 設計文件

## 背景

`index.html` 是一個單檔的全螢幕影片播放頁。目前流程：

1. 載入後顯示中央 overlay（半透明遮罩 + 白色圓形播放鍵 + 「點擊播放」文字）。
2. 使用者點擊 overlay → 進入瀏覽器全螢幕 + 帶聲音播放，overlay 淡出。
3. 影片播完後停在最後一幀，沒有任何後續操作入口。

本次新增：影片播放結束後，於畫面右下角顯示一顆**純 icon、無文字**的 replay 按鈕，讓使用者可重新觀看。

## 目標

- 影片 `ended` 時，右下角淡入一顆 replay 按鈕。
- 按鈕只有 icon，不顯示任何文字。
- 點擊後從頭重播，並維持全螢幕、帶聲音。
- 視覺語言沿用現有極簡黑底 + 白色細邊圓鈕風格。

## 非目標（YAGNI）

- 不加入進度條、音量、暫停等原生或自製播放控制項。
- 不加入分享、下載等其他按鈕。
- 不改動現有「點擊播放 + 進入全螢幕」的初始流程。

## 設計

### Icon 渲染方式

採用 **inline SVG 環形箭頭（↻）**：

- 白色線條的標準 replay 環形箭頭，以內嵌 SVG path 繪製。
- 理由：線條乾淨銳利、跨螢幕一致、零外部檔案、與現有白色播放鍵屬同一套視覺語言。
- 已排除：純 CSS 畫環形箭頭（邊緣醜、hacky）、Unicode/Emoji 字元（跨平台渲染不一致、風格不搭）。

### 版面與外觀

- 按鈕 `position: fixed`，固定於右下角，距右、下邊各約 24px。
- 尺寸約 56px 的圓形（比中央 84px 播放鍵小一號）。
- 樣式沿用現有 `#overlay .icon`：半透明白底（`rgba(255,255,255,0.12)`）+ 白色細邊（`2px solid rgba(255,255,255,0.85)`）。
- 圓內置中放白色 SVG 環形箭頭，無文字。
- 預設隱藏（`opacity: 0` + `pointer-events: none`），沿用現有 0.4s opacity transition 淡入／淡出。
- 滑鼠 hover 時微調背景透明度，提供可點擊回饋。
- `cursor: pointer`。

### 行為與資料流

1. 監聽 `player` 的 `ended` 事件 → 為按鈕加上顯示狀態（移除 hidden class），淡入。
   - **不使用 `{ once: true }`**，因為重播後若再次播完，按鈕需再次出現，可重複 replay。
2. 監聽按鈕 `click` 事件：
   - `player.currentTime = 0`
   - `player.play()`（沿用現有對 play() 回傳 promise 的 `.catch` 防護）
   - 將按鈕切回隱藏狀態（加回 hidden class）。
   - 維持目前全螢幕狀態，不重新請求也不退出全螢幕。
3. 不顯示原生 video controls，維持乾淨畫面。

### 錯誤處理

- `player.play()` 回傳的 promise 以 `.catch` 包覆並靜默忽略（與現有 `start()` 一致），避免瀏覽器自動播放政策造成未捕捉的 rejection。

## 影響範圍

僅修改 `index.html` 單一檔案：

- **HTML**：新增 replay 按鈕的 DOM 節點（含 inline SVG）。
- **CSS**：新增按鈕定位、外觀、hidden 狀態、hover 樣式。
- **JS**：新增 `ended` 與按鈕 `click` 兩個事件監聽。

不更動現有點擊播放／全螢幕邏輯。專案無 API router，故不涉及 swagger 文件調整。

## 測試構想

此為純前端單檔頁面，建議以手動驗證為主：

1. 載入頁面 → 點擊播放 → 影片正常播放。
2. 影片播完 → 右下角淡入 replay 按鈕，僅有 icon、無文字。
3. 點擊 replay → 影片從頭播放、維持全螢幕、有聲音、按鈕淡出。
4. 第二次播完 → 按鈕再次出現（驗證可重複 replay）。
5. hover 按鈕 → 有亮度回饋。
